# NEGATIVE CORNER：负结果与失效边界

这个文件只放**不利于卖点**的读数。它们不削弱主结果（B2 只生长方向 3/3 训练流为正），
但决定了这个仓库的结论边界：**能说到哪、不能说到哪**。

口径约定：
- 「S4」= seed 41/43/44 的确认实验（候选、seed 全链重探针）；「S6」= seed 45/46/47 的确认实验。
- 负结果按用户 2026-11-11 口径只写在这里，不单独出仓库、不做卖点。
- 所有数字来自 `results/S6-confirm-summary.json`、`results/S4-confirm-summary.json`、
  `results/S4-noise-floor-precheck.json`、`results/S5-k-scan.json`、`results/S3-pilot.json`（原件在课题仓）。

## 1. 只剪枝臂 B1：S4 上单独有害，S6 上翻转

B1 = 只剪掉 k=10 条最低贡献边，不补边。catch rate 相对 B0 的配对差：

| seed | B0 | B1 | B1−B0 | 备注 |
|---|---|---|---|---|
| 41 | 0.7647 | 0.5750 | **−18.97pp** | 单流最差，掉近 19 个点 |
| 43 | 0.8029 | 0.8625 | +5.96pp | |
| 44 | 0.7051 | 0.7632 | +5.81pp | |
| **S4 合并** | | | **−2.40pp** | 方向不成立 |

但 S6 的描述性读数完全相反：B1−B0 = **+8.86 / +11.36 / +1.70pp**（3/3 正）。
按 D13 预注册，B1 不进判决，只作描述性记录。

**所以准确说法是**：剪枝单独在 S4 上合并 −2.40pp、单流最差 −18.97pp；
在两个 seed 集上方向相反，**不能**声称「剪枝单独有害」是稳定结论，只能说它从未被证明有稳定增益。

## 2. 剪+长臂 B3：确认级负结果，且不如只长

B3 = 剪 k 条 + 长 k 条（原始假设 H_TND）。相对 B0 的配对差：

| seed | B0 | B3 | B3−B0 |
|---|---|---|---|
| 41 | 0.7647 | 0.5239 | **−24.08pp** |
| 43 | 0.8029 | 0.8228 | +1.99pp |
| 44 | 0.7051 | 0.8452 | +14.01pp |
| **S4 合并** | | | **−2.70pp**（verdict=inconclusive，2/3 正） |

与同批 B2 比较（S4 探索性拆成分）：**B3 合并 −2.70pp vs B2 合并 +7.12pp**。

S6 描述性读数：B3−B0 = +11.14 / +8.82 / +14.39pp，合并 **+11.45pp**，
**低于 B2 的 +16.06pp**，且 3 个 seed 里有 2 个低于 B2（seed47 反转：B3 +14.39 > B2 +6.18）。

**结论**：加了剪枝的 B3 在两批 seed 上都没有超过只生长臂 B2；H_TND 正式判定是
inconclusive（S4 合并 −2.70pp，未到 −5pp 的 falsified 线，但方向不成立）。
「先剪再长」不是这个任务上更好的规则——这是仓库里最贵的负结果。

## 3. seed47 时延 +46.14%：破 20% 预算，正式 verdict 因此是 inconclusive

S6 的预注册判据要求「B2 时延增幅 ≤20%」。三个 seed 的实测：

| seed | B0 中位时延 (ms) | B2 中位时延 (ms) | 增幅 | 是否过门 |
|---|---|---|---|---|
| 45 | 0.1549 | 0.1420 | −8.33% | 过 |
| 46 | 0.1569 | 0.1641 | +4.62% | 过 |
| 47 | 0.1294 | 0.1891 | **+46.14%** | **破门** |

按预注册规则（supported 需要三个 seed 全过时延门），**正式 verdict = inconclusive**，
不是 supported。这一点不因为「方向 3/3 正」而改写。

**但要如实说明测量问题**：同一 seed、同一 k=10 臂、边数同为 137063 的两次独立测量，
时延读数可以差几十个百分点：

| 对照 | 一次读数 | 另一次读数 |
|---|---|---|
| seed45 k=10（S6 vs S5 锚点重跑） | −8.33% | **+12.19%** |
| seed47 k=10（S6 vs S5 锚点重跑） | +46.14% | **−20.09%** |
| 全臂边数同为 137063 时，扫描内读数范围 | **−38.73%** | **+47.78%** |

也就是说：时延比值门对分母（B0 的单步时延，0.13–0.16ms 量级）漂移极其敏感，
它测到的更多是测量噪声而非「B2 真的慢 46%」。**但本仓库不据此翻案**——
预注册口径就是预注册口径，这里只登记「破门」这个事实和「门本身不硬」这个观察。

## 4. pilot 阶段的 +17.5pp 是 3 局噪声，不是效应

S3 pilot（1 个训练流、3 局评测）曾给出 B3−B0 = **+17.52pp**（B0 0.7206 → B3 0.8958），
当时看起来是大效应。S4 的轴隔离噪声地板（候选集冻结、k=10、v2、190 步、**10 局**）给出的数字：

| 口径 | B3−B0 |
|---|---|
| S3 pilot：3 局（2026–2028） | **+17.52pp** |
| 噪声地板：同流同候选，10 局（2026–2035） | **+1.51pp** |
| 噪声地板：训练序换 seed41 置换，10 局 | **−15.08pp** |
| 噪声地板：训练序换 seed43 置换，10 局 | **−17.46pp** |
| 噪声地板：只换评测局表（2101–2110），10 局 | +10.81pp |

读法：3 局口径的采样噪声本身就有 ±9pp 量级（局表轴 +1.5 → +10.8pp），
+17.5pp 的「效应」在换成 10 局后只剩 +1.5pp，换训练序直接翻负。
**所以本仓库的主结果一律用 10 局 × 3 seed = 30 对 episode，不用 3 局数字。**

## 5. 剂量：k=10 不是「最优剂量」，只是被选中的工作点

S5 的剂量扫描（同 3 个训练流，探索性，不回写 H_B2 判决）：

| k | 合并 B2−B0 |
|---|---|
| 10 | **+16.06pp** |
| 50 | +10.95pp |
| 100 | +8.20pp |
| 287（候选池上限） | +8.55pp |

- 没有任何 k>10 达到 +21pp，**k=10 已近饱和**（预注册规则 2 触发）。
- 但流层形状反转：seed45 在 k=287 转负（**−6.07pp**），seed47 在 k=287 最高（**+26.01pp**）。
  所以「k=10 对所有流最优」是错的，只能说「合并层 k=10 最好、且这是事后扫描，不是确认」。
- 高 k 的时延读数同样破门（seed46 k=50 +47.78%），与 §3 的噪声问题同源。

## 6. 这个结论不覆盖什么

1. **工作点**：全部在主结果在「统一稳定化（v2）扰动后的恢复学习」上测得，
   不外推到原生 checkpoint 的事后修复（D9 边界声明）。
2. **评测轴**：评测局表固定 2026–2035 跨 seed 使用，局表轴本身有约 9.3pp 摆幅，
   没有被 seed 覆盖；+16.06pp 应理解为「这个局表口径下的效应」。
3. **独立流数量**：3 个 seed 是 3 条训练流，不是 3 个独立数据集；跨 6 个训练流
   （S4 的 41/43/44 + S6 的 45/46/47）方向零负例，但其中 3 个流的幅度只有 +1.62/+3.64/+16.10pp（S4 探索性 B2 读数）。
4. **剪枝规则**：B1/B3 的负结果只否定了这一条剪枝规则（bottom-25% ∩ 最低 S 10% ∩ 5% 预算），
   不能外推到「所有剪枝都不行」。
